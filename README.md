# Multi-Cycle_Processor
CE 4304 Computer Architecture Final Project

## Specifications
* Target Market: Embedded Systems Computer
* Memory Organization: Harvard architecture
* Address Bus Width: 10 bits
* Number of Addresses 1024
* Program Load Address: 0x200
* Data Bus Width: 36 bits
* Number of Register File Address Bits: 2
* Number Register File Registers: 4
* Width of Register File Register : 36
* Instruction Width: 20 bits
* Size of Immediate Field: 8 bits
* Maximum number of Instructions: 64
* Memory Addressing Endianess : Little
